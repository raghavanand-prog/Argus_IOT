# Security Policy

## Supported versions

Only the latest version on the default branch receives security fixes.

## Reporting a vulnerability

Please **do not open a public issue** for security problems.

Report it privately through GitHub instead: go to the **Security** tab of this
repository and click **Report a vulnerability**.

Please include:
- a description of the issue and its impact
- steps to reproduce, or a proof of concept
- affected files, endpoints or versions

I aim to acknowledge reports within 72 hours and will keep you updated until
the issue is resolved. Thanks for helping keep this project secure.
